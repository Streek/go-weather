# Product

Console Go Weather retrieves current conditions, daily forecasts, and the next 24 hours from Open-Meteo. Users can enter a postal code or city, choose text or table output, select metric or imperial units, enable or disable color, and save a default location and preferences.

Preferences are stored under `~/.weather_config/weather_config.json`; weather responses are cached for one hour in a mode-0700 temporary directory.
