# Features

- Current weather, seven-day daily forecasts, and 24-hour hourly forecasts.
- Postal-code or city-name geocoding through Open-Meteo.
- Text and table display modes with metric or imperial units and optional ANSI colors.
- Saved location/preferences and one-hour weather caching.
- Go tests, vet, formatting checks, binary build, and optional Arch package workflow.

The CLI has no backend, user account, credentials, or service deployment surface.
